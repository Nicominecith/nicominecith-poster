# Bundled fonts

Every face in this directory ships with the app, so a poster never fetches a font
from a third party and an export can embed the exact bytes it rendered. The files
are the latin subsets published by Fontsource, in regular and, where the family
has one, bold.

The `*.fallback.ttf` files are not families a poster can be set in. They are the
faces the renderer reaches for when the family it is set in has no glyph for a
character — a Polish, Turkish, Greek, Cyrillic or Vietnamese title, or a ★ in a
track name — because a latin subset carries none of those. They are cut from
DejaVu by `libs/fonts/scripts/build-fallback-fonts.py` and are fetched only by a poster
whose text actually needs one.

Every other script — Devanagari, Arabic, Hebrew, Thai, Chinese, Japanese, Korean,
emoji and the rest — prints from the Noto faces installed as the `@fontsource/noto-*`
packages listed in `package.json`, fetched the same way and only by a poster that
needs them (see `libs/renderer/README.md`). Noto is copyright The Noto
Project Authors (https://github.com/notofonts), and every family is licensed under
the SIL Open Font License 1.1, whose text ships inside each package.
